
                =========================
                Adjustable Blinking Light
                =========================


/// ---------- Entry 1 -- February-27-2026 ----------

# TOOLS USED:
# 5x MtM cables (2 large - green, 3 small - brown)
# 1x LED light (I used green)
# 1x Potentiometer
# 1x Arduino Uno

After completing the blinking light project, I wanted to challenge myself by modifying
the circuit. I decided to create a light that would adjust the resistance in the circuit
using a potentiometer. I considered it a fun challenge, and would actually teach me how
to properly implement potentiometers in my projects.

In this project, I had also used the provided development/breakout board that came with
the arduino in the kit. It helped me to understand how development boards are used (like 
indirectly testing a circuit on the board), and how they can be used in the future (to
create new boards with soldering tools). This was a tool I hadn't used in the original
blinking light project.
